# Trusted offline Modrinth plugin manager

Admin > Nodes > Instance reservations > Plugin manager. Requires a Paper/Purpur reservation with a matching local Docker/Podman fleet; start OMCP Connect with `--allow-fleet-plugins`. The installed software provenance must match the reservation. Stop the server before any plugin operation.

Search uses the documented Modrinth v2 search and project-version endpoints (https://docs.modrinth.com/api/operations/searchprojects/ and https://docs.modrinth.com/api/operations/getprojectversions/). Exact selected version is fetched again by the connector, including loader, Minecraft version, release channel, size and SHA-512. HTTPS-only fixed provider origins, no redirects, bounded metadata and 64 MiB JAR limit. No arbitrary download URL is accepted. Required or incompatible dependencies are refused rather than installed automatically. Review publisher, license and executable code before confirming. Checksums prove content consistency, not safety.

Installed files use OMCP-managed names with project/version IDs. No overwrites; a project must be removed manually via this manager before a replacement can be installed. Enable/disable changes the suffix, delete removes only the selected managed JAR, preserving data folders. Only managed entries are listed. Restart to load changes. Existing manually installed plugins are outside this manager. No live hot reload, automated dependency resolution, upgrades/rollback, Hangar integration, customer access or general disk quota yet. The tests use fixture responses/JARs and do not prove live provider availability or plugin execution.

## Hangar provider

The same offline admin UI now has a Hangar provider selector. The implementation uses the published Hangar v1 project search, project version and exact version ID endpoints (https://hangar.papermc.io/api-docs), with response fields checked against the upstream HangarMC/Hangar Version, FileInfo and PlatformVersionDownload models. Only public, reviewed Release channel PAPER builds with an exact supported Minecraft version, hosted Hangar CDN download, size and SHA-256 are eligible. External links, hidden/unstable channels and required dependencies are refused. Hangar-managed filenames include a provider namespace. Fixture tests exercise selection and install/toggle/delete. Live API/download and actual plugin execution still need verification. No arbitrary URLs, automatic dependency resolution, or untrusted customer installation.
